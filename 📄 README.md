Interactive Power BI dashboard for analyzing Q-Commerce orders, revenue, delivery performance, customer behavior, app performance, payment modes, and city-tier trends using DAX and interactive visualizations.

# 🛵 Q-Commerce Sales & Delivery Analytics Dashboard

An interactive **Power BI Business Intelligence project** designed to analyze Q-Commerce operations, sales performance, customer behavior, order trends, and delivery performance.

The dashboard transforms raw Q-Commerce data into meaningful business insights using **Power BI, DAX, data modeling, KPIs, interactive slicers, and dynamic visualizations**.

---

## 📊 Project Overview

Q-Commerce (Quick Commerce) focuses on delivering groceries, food, and everyday products to customers within a short time frame.

This project analyzes Q-Commerce business performance across multiple dimensions, including:

* 📦 Order performance
* 💰 Revenue analysis
* 🚚 Delivery performance
* ⭐ Customer ratings
* 👥 Customer/user types
* 📱 App-wise performance
* 🏙️ City-tier performance
* 💳 Payment modes
* 📅 Monthly & quarterly trends
* ❌ Cancelled and returned orders

The dashboard is designed to help business teams identify trends, compare performance, and make data-driven decisions.

---

## 🎯 Project Objectives

The main objectives of this project are:

1. Analyze overall Q-Commerce sales and order performance.
2. Track total revenue, orders, items, ratings, and Average Order Value (AOV).
3. Analyze revenue trends across months and quarters.
4. Compare revenue performance across different Q-Commerce apps.
5. Analyze orders and delivery performance.
6. Identify cancelled and returned order patterns.
7. Compare performance across different city tiers.
8. Understand customer/user-type behavior.
9. Analyze payment-mode contribution to revenue.
10. Identify important business trends and opportunities.
